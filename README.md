# Acceleret

**Software built around how your business works.**

Acceleret is a software studio in Surat, India. We build CRM and ERP systems, workflow automation,
AI-assisted processes, web portals, apps and integrations, working on-site with each team so the
software fits how the business already runs.

[acceleret.com](https://acceleret.com) · [support@acceleret.com](mailto:support@acceleret.com)

## Built with

Next.js, React, TypeScript, Tailwind CSS, GSAP, Payload CMS and PostgreSQL.
